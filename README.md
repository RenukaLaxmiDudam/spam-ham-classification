# Spam and Ham Classification

## Project Overview

This project focuses on classifying text messages as either **Spam** or **Ham** using Natural Language Processing (NLP) and Machine Learning techniques.

## Dataset

The dataset contains text messages with two attributes:

* **Category** – Label of the message (`spam` or `ham`)
* **Message** – Actual text message

### Dataset Link

[Google Drive Dataset](https://drive.google.com/file/d/1U26unaY18thdWTN5dfumLy9W2aHIvpGR/view?usp=drive_link)

## Project Sprints

### Sprint 0 – Exploratory Data Analysis

* Understand the dataset
* Define the problem statement
* Check missing values and duplicate records
* Perform data cleaning
* Identify data types
* Analyze spam and ham distribution
* Create basic visualizations
* Identify patterns and relationships in the data

### Sprint 1 – Preprocessing

* Clean the text data
* Perform feature engineering
* Convert text into numerical features
* Split data into training and testing sets
* Prepare the data for machine learning

### Sprint 2 – Model Development

* Train machine learning models
* Make predictions
* Evaluate model performance using appropriate metrics

### Sprint 3 – NLP Architecture

* Develop an NLP-based architecture
* Train the model
* Evaluate performance using metrics such as accuracy, precision, recall and F1-score

### Sprint 4 – Deployment

* Deploy the trained Spam and Ham classification model
* Provide an interface for predicting whether a message is Spam or Ham
